# مشروعي الأول

## نبذة عن المشروع

هذا المشروع هو مساحتي الخاصة لتعلم البرمجة من الصفر. سأحفظ هنا ما أتعلمه خطوة بخطوة، وأسجّل تقدّمي مع الوقت، وأتدرّب على استخدام GitHub بشكل عملي.

## أهداف التعلم

- فهم أساسيات البرمجة: ما هو الكود، وكيف يعمل الحاسوب بالتعليمات.
- تعلّم لغة برمجة أولى سهلة (مثل Python).
- التعرّف على GitHub: المستودعات (Repositories)، والملفات، وحفظ التغييرات (Commits).
- كتابة برامج صغيرة بنفسي وتجربتها.
- بناء عادة تعلّم منتظمة وتوثيق ما أنجزته.

## الخطة التعليمية للمبتدئين

1. **الأسبوع 1: التعرّف على الأساس**
   - ما هي البرمجة؟ وما هو GitHub؟
   - فهم ملف README وكيفية تعديله.
2. **الأسبوع 2: أول برنامج**
   - كتابة أول برنامج يطبع "مرحبًا بالعالم".
   - فهم المتغيرات (Variables) والنصوص والأرقام.
3. **الأسبوع 3: اتخاذ القرارات**
   - الشروط (if / else).
   - تمارين صغيرة على الشروط.
4. **الأسبوع 4: التكرار**
   - الحلقات (Loops).
   - تمارين صغيرة على التكرار.
5. **الأسبوع 5: مشروع صغير**
   - بناء برنامج بسيط يجمع ما تعلمته (مثل آلة حاسبة صغيرة).
